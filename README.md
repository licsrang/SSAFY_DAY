# SSAFY DAY
매달 하루, 우리답게. 우리 반의 월별 이벤트 아지트입니다.

## 공개 홈페이지
https://licsrang.github.io/SSAFY_DAY/

## 월별 이벤트
- 9월: 이미지 속 세 키워드 맞히기. 새로 제작한 10문제, 초성 힌트, 이전/다음 이동, 결과 표시. 게임 진행은 이 화면에만 유지됩니다.
- 10월: 일상 속 알고리즘 주관식 10문제. 상황 이미지 → 큰 텍스트 힌트 → 대표 정답과 인정 가능한 다른 풀이. 진행자가 빔프로젝터로 띄우고 팀별 종이 답안으로 진행합니다.
- 11~12월: 수정 가능한 기획 예시.

## 진행자 사용법
월별 탭에서 시작하기를 누르면 해당 게임으로 이동합니다.
10월 바로가기: https://licsrang.github.io/SSAFY_DAY/#play-10
10월 ‘발표 화면’을 누르면 메뉴가 숨겨지고 그림과 진행 버튼이 커집니다. 힌트와 해설은 화면 가운데 창으로 표시되며 Esc로 닫을 수 있습니다. 60초 타이머는 자동으로 다음 문제로 넘기지 않으며 힌트/해설을 열 때 잠시 멈춥니다.
9월 키워드 정답은 입력 순서와 관계없이 확인되며, 힌트는 세 키워드 칸에 표시됩니다. 앞뒤로 이동해도 각 문제의 상태가 유지됩니다. 새로고침 시 다시 시작합니다.

## 수정
설치나 빌드 없이 index.html을 열거나 정적 웹서버로 실행할 수 있습니다.
- events.js: 월별 행사 제목과 소개
- keyword-game.js: 9월 게임과 정답, 동의어
- algorithm-questions.js: 10월 문제와 힌트·해설
- algorithm-game.js: 10월 진행 화면
- assets/: 생성 이미지

10월 이미지는 일상 상황을 표현한 창작 이미지이며 정확한 문제 조건은 텍스트 힌트로 확인합니다. 정답과 다른 풀이의 적절성은 진행자가 조건을 기준으로 판단합니다. 자동 채점이나 공동 점수 집계 기능은 없습니다.

준비 체크와 9월 기존 빙고의 브라우저 저장 기능 외에 서버 저장은 없습니다. Google Fonts를 사용할 수 없어도 시스템 글꼴로 표시됩니다. SSAFY 공식 홈페이지가 아닙니다.
